## About the Application
Agentic AI Application that allows uploading resume documents and analyzing the document with the ability to ask OpenAI about the data.

## Features

1- Upload resume: Upload resume as pdf and ingest it to pinecone. 

2- Chat : Answer questions based on data in pinecone & openai

## Technologies

1- Next.js

2- TailwindCSS

3- OpenAI

4- LangChain

5- LangSmith

6- Pinecone
